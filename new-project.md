# CarFox

CarFox is a mobile app where sellers can list and sell their cars online.

## Core idea

- Sellers create car listings with photos, price, and details.
- Buyers browse listings and contact sellers.
- The app makes online car selling simple and fast.

## Next build steps

1. Define screens (home, listing details, add listing, profile).
2. Choose tech stack (Flutter or React Native).
3. Set up authentication for sellers and buyers.
4. Build listing upload flow with images.
5. Add search and filters (price, model, location).
